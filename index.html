FastOS

GitHub

ดิสโทร Linux ที่สร้างขึ้นเองตั้งแต่ต้น ตามแนวทาง Linux From Scratch (LFS) ใช้ Linux Kernel เวอร์ชัน 6.6.21 (LTS) เป็นแกนหลัก โปรเจกต์นี้ทำขึ้นเพื่อศึกษาเจาะลึกสถาปัตยกรรมของระบบปฏิบัติการ ตั้งแต่ kernel, bootloader ไปจนถึง userland และใช้เป็นผลงานแสดงทักษะด้าน systems development

A custom-built Linux distribution, built from scratch following the Linux From Scratch (LFS) approach, running Linux Kernel 6.6.21 (LTS). Created as a deep-dive into Linux OS architecture — from the kernel and bootloader up through userland — and as a portfolio piece demonstrating systems development skills.

  • เข้าใจ Linux อย่างลึกซึ้ง compile kernel, สร้าง toolchain และประกอบ root filesystem เอง แทนการใช้ดิสโทรสำเร็จรูป
  • Deeply understand Linux compile the kernel, build the toolchain, and assemble the root filesystem by hand rather than using a pre-built distro
  • ระบบที่เข้าใจได้ทุกส่วน ทุกคอมโพเนนต์เลือกและ compile จาก source อย่างตั้งใจ
  • A fully understood system every component deliberately chosen and compiled from source
  • รากฐานให้ต่อยอดได้ วางโครงสร้างให้ปรับแต่งและขยายฟีเจอร์ได้ในอนาคต
  • A foundation to build on structured for future customization and extension

firstOS

GitHub

เคอร์เนลระบบปฏิบัติการ x86 ขนาดเล็กที่เขียนด้วยภาษา C และ Assembly บูตผ่าน Multiboot 1 ตั้งค่าโหมด VGA text mode และแสดงข้อความเริ่มต้นระบบ โปรเจกต์นี้เป็นจุดเริ่มต้นของการศึกษา การพัฒนา OS ระดับ low-level ก่อนต่อยอดไปเป็น FastOS

A small x86 hobby operating system kernel written in C and assembly. It boots via Multiboot 1, initializes VGA text mode, and prints a startup banner. This project was the starting point for learning low-level OS development, later extended into the FastOS project.

  • เริ่มต้นจากศูนย์ เขียน entry point, boot sequence และ 32-bit protected mode เอง
  • Started from zero hand-written entry point, boot sequence, and 32-bit protected mode setup
  • พื้นฐานสำหรับต่อยอด วางโครงสร้างไว้สำหรับ GDT/IDT, memory management, paging และ interrupt handling ในอนาคต
  • Foundation to build on structured for future GDT/IDT setup, memory management, paging, and interrupt handling
